# Legion SRC

[Легион - legiongame.gg](https://legiongeme.gg)

## Что это?!?

Legion SRC - сайд-проект для сбора исходников игры (Точнее её фронтенда)

Продолжает мой же прошлый проект по исходникам, но без такой автоматизации  
Потом мб решу как автоматизировать нормально (возможно верну тот нормальный скрипт с авто-пушем обновлений)

### Код отличается от сайта?!?

Да, но нет. Для своего и и вашего удобства на всех JS файлах используется Biome  
Он быстрый и сочетает в себе как линтер, так и форматтер, по этому выбран именно он

### Последние версии

Если нужны файлы самой последней версии или без форматирования - используйте скрипт sync.sh (Для Linux и MacOS\*)  
Скрипт использует ссылки из файла [paths](paths) напрямую и ваш LSID из игры (можно взять в Cookie браузера)

P.S не гоняйте сильно пацаны, а то если перестараетесь, то DOS будет и **наказывается!** + Зак злой будет >w< (А он и забанить может)
